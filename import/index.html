The City points with nothing in OSM within 30 m, cut into geographically compact chunks of up to 250, one changeset each. Points listed as far or duplicate on the gap page already have an OSM feature and are not here, nor is a missing point the City lists as temporarily removed. Columns and shelter boards are chunked apart, so either can be imported without the other. Chunks are recut from the gap list at every weekly build: reopen this page before starting one. The import's community review is not done here: this page is the technical half only.

  1. Start JOSM with Preferences → Remote Control on.
  2. 1 load opens the chunk as a new layer, with the changeset comment and tags set.
  3. 2 context adds, to that layer, the existing OSM boards, advertising and shelters in the chunk's box, from Overpass.
  4. Check the new nodes against imagery and the validator, then upload.
